# literature/

Our literature review: what others have done, and what is still missing.
It becomes the related-work part of the report's Introduction (about half a page).

| File | What goes in it |
|---|---|
| `papers.md` | One short entry per paper we read, plus topics still to search |

## Rules

- One entry per paper, using the template in `papers.md`. Five lines are enough.
- Every entry ends with "How it relates to our project". That line is what we cite for.
- No PDFs in this folder. The repository is public and most papers are copyrighted:
  link to the ACL Anthology, arXiv or the publisher instead.
- BibTeX goes straight into Overleaf (the "Cite" button on the ACL Anthology or arXiv page).
- Read the paper itself, not a summary of it. If an AI tool helped you find or summarise
  a paper, log it in `notes/ai_use.md`.

## The question we want to answer

Has anyone measured what *ambiguous* diacritic loss (Class B) costs machine translation,
separately from harmless loss (Class A), for Portuguese? If yes, how do we differ? If no,
that gap is our contribution.
